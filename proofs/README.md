# Laws for the offline server

[Bend](https://bend-lang.com) models of the server's game rules, with laws
that state what the rules must guarantee and machine-checked proofs that they do.

- `LAWS.bend` states the laws. Read this file to know what is guaranteed.
- `PROOF.bend` proves each law (`def L.<law>`). `./check.sh` is the gate: it prints
  `ALL PROOFS CHECK` only when every law holds, rechecked by the Lean-proven kernel.
- The models mirror the Legible code they are named after:

| model | mirrors | laws |
|---|---|---|
| `Raid.bend` | `Server/raid.lbl`: steps, fights, health | `raid_*` |
| `Board.bend` | `Server/gamedata.lbl` story maps and `quest_can_move` | `board_*` |
| `Walk.bend` | `Server/fakeserver.lbl` `moved_offsets`, `position_after_win` | `walk_*` |
| `Abilities.bend` | `kit_abilities`, the roster, `Server/data/stat_modifiers.json` and `stat_mod_appears.json` | `abilities_*`, `kits_*` |
| `Campaign.bend` | the verification switch in `bot_abilities`, `Server/data/campaign.json` and `campaign_batches.json` | `campaign_*`, `batches_*`, `kits_carry_verified_effects` |
| `Stats.bend` | `base_stats`, `special_damage_ratios` | `stats_*`, `specials_*` |

`Data.bend` is generated by `gen_data.py` from the server's own files (the statMods
catalog, the ability cards, the kit table, the roster, the special ratios), so the ability
and special laws check the data that ships. `gen_glossary.py` writes `../ABILITY_GLOSSARY.md`
from the same files and `effect_status.json` (which effect classes are verified, with the
evidence). Do not edit either output; `check.sh` regenerates both.

A model is a copy of the rule, not the rule itself. Where a law caught a flaw, the Legible
code was fixed and a Legible test checks the same property against the real code:
`test_server_accepts_exactly_the_moves_the_client_offers` (test_gamedata.lbl) and
`test_reported_health_is_kept_within_full_health` (test_raid.lbl),
`test_campaign_off_serves_the_shipped_rows` and `test_active_batch_goes_to_the_probe_bot_alone` (test_gamedata.lbl, mirroring the campaign laws),
`test_every_carried_ability_has_a_served_card` (test_gamedata.lbl, after `abilities_carded`
caught the Overcharge card claiming special attacks for a row that fires on every hit). When you change one of
the mirrored functions, change its model the same way and run `./check.sh`.

Install Bend with `curl -fsSL https://bend-lang.com/install.sh | sh`; `bend guide` explains
the syntax of laws and proofs.
